<h1 align="center">DoWorkoutDaily</h1>

<p align="center">
  A clean & motivating Workout Tracker app built for Android using Kotlin & Jetpack Compose
</p>

---

**DoWorkoutDaily** is a modern **fitness and workout tracking application** built with **Kotlin** and **Jetpack Compose**.  
It helps users stay consistent with their daily workouts, track fitness routines, and build healthier habits through a simple and motivating experience.

Think of it as your **digital fitness companion** for consistency, discipline, and self-improvement.

## Features

- Track daily workout routines
- Clean and motivating UI
- Workout consistency tracking
- Lightweight and smooth performance
- Simple and distraction-free experience
- Built with modern Android development tools
- Responsive UI using Jetpack Compose

---

## Tech Stack

- **Kotlin**
- **Jetpack Compose**
- **Material 3**
- **Room Database**
- **Hilt** (Dependency Injection)
- **Coroutines**
- **MVVM Architecture**
